# MathCAS – udgivelser

MathCAS er et dansk program til matematik, fysik, kemi og statistik: dokument, CAS, grafer og R-Statistik samlet ét sted, så hele opgaven kan skrives, regnes og afleveres i samme program. MathCAS er gratis og kræver ingen konto.

**Hent MathCAS** under [Releases](https://github.com/Hamidqa/MathCAS-udgivelser/releases/latest) eller på [mathcas.dk](https://mathcas.dk).

| Udgave | Fil |
|---|---|
| Mac med Apple Silicon (M1, M2, M3 …) | `MathCAS-<version>-mac-arm64.dmg` |
| Mac med Intel | `MathCAS-<version>-mac-x64.dmg` |
| Windows 10 og 11 (64-bit) | `MathCAS-<version>-win-x64.exe` |

Kræver macOS 14 eller nyere. Den installerede app opdaterer sig selv fra udgivelserne her.

## Hvad ligger her?

Dette repo indeholder **kun de færdige installationsfiler** (under Releases) og kildekoden til de frie tredjepartskomponenter, der følger med (mappen [`kildekode/`](kildekode/)). MathCAS' egen kildekode er ikke offentlig.
